개인정보처리방침

오운일분(이하 '채널')과 채널 운영 도구(이하 '도구')가 정보를 다루는 방법입니다.

1. 이 도구는 누가 쓰나요

도구는 채널 운영자 한 사람이 자기 컴퓨터(맥)에서만 실행하는 프로그램입니다. 일반 시청자는 도구에 로그인하거나 정보를 입력하지 않습니다. 도구는 운영자 본인의 계정에만 연결됩니다.

2. 다루는 정보와 목적

정보목적
운영자 본인의 유튜브 채널 정보 · 업로드 권한 (YouTube Data API)채널 영상 업로드, 재생목록 추가, 내 채널 확인
운영자 채널의 통계 (YouTube Analytics API · 조회수 · 구독자 수 등 합계)어떤 영상이 잘 보였는지 운영자가 확인
운영자 채널 영상에 달린 공개 댓글운영자가 답글을 확인 · 작성 (운영자가 승인해야 올라감)
운영자 본인의 인스타그램 · 페이스북 페이지 · 스레드 · 틱톡 게시 권한같은 영상 · 카드뉴스를 운영자 계정에 게시

시청자 개인을 식별하는 정보(이름·연락처·생년월일 등)는 수집하지 않습니다. 댓글은 각 플랫폼에 공개된 내용을 운영자 화면에 보여 주는 용도로만 쓰고, 다른 곳에 팔거나 넘기지 않습니다.

3. 보관 장소와 기간

  • 로그인 토큰과 기록은 운영자의 컴퓨터 안에만 저장되며, 별도 서버로 보내지 않습니다.
  • 통계 · 댓글 기록은 운영을 위해 필요한 동안 보관하고, 운영자가 도구에서 지우거나 연결을 끊으면 함께 지웁니다.
  • 제3자에게 제공하거나 판매하지 않습니다. 광고 목적으로 쓰지 않습니다.

4. YouTube API 서비스

도구는 YouTube API 서비스를 사용합니다. 이용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

연결을 끊으려면 Google 계정 › 보안 › 타사 액세스에서 '오운일분'의 권한을 삭제하면 됩니다. 삭제하면 도구는 더 이상 채널에 접근하지 못하고, 저장된 토큰은 쓸 수 없게 됩니다.
